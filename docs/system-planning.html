Workstream A
经销商 Training System (LMS)
Self-paced onboarding portal · 5–7 modules · 2-week completion window · In-person calendar booking
Objective

Standardise onboarding for all new 经销商 with structured, trackable digital training covering culture, policy, products, and SOP.

Target Users

New 经销商 (self-paced learners), Admin (content managers), PIC (in-person training coordinator)

Key Metrics

Completion rate, Quiz pass rate (≥70%), Time-to-complete, In-person booking conversion

Proposed Training Modules
🏢
Module 1
Company Culture
Brand story, vision, mission, values
📜
Module 2
经销商 Policy
T&C, commission, conduct rules
💄
Module 3
Product Training
OEM formulations, ingredients, benefits
📋
Module 4
SOP
Order handling, customer service, returns

+ Modules 5–7: to be defined (e.g. Sales Scripts, Social Media SOP, Promotions Policy). Each module ends with 20-question quiz — 70 marks to pass.

• Organise into module folders
• Gap analysis on missing content
• Define quiz questions per module
Phase 2
Platform Setup
Weeks 2–4
• Select & configure LMS
• Build module structure
• Upload content & embed videos
• Set quiz logic (70 pass mark)
Phase 3
Automation & Calendar
Weeks 4–6
• Notification to PIC on completion
• In-person booking calendar
• Seat / slot management
• Completion certificate setup
Phase 4
Admin Panel & Testing
Weeks 6–8
• Admin: add/edit/delete content
• Learner progress dashboard
• UAT with pilot 经销商
• Go-live & monitor
